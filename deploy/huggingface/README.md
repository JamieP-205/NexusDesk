# NexusDesk browser demo

A practice IT helpdesk built with Java, Spring Boot, Spring Security and SQL. Choose employee,
technician or administrator on the sign-in page. Each visitor gets a private copy of the fictional
data, deleted when they sign out or after an hour without activity.

Source, documentation and how it was built: https://github.com/JamieP-205/NexusDesk
