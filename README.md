# NexusDesk
Client: Northstar Digital Solutions Ltd. 
Project Type: Internal Business Software 
My Role: Junior Software Developer Project Status: 
New Development Target Platform: 
Desktop/Web Application

# Background
Northstar Digital Solutions is a growing company with approximately 60 employees.
The company currently manages IT support requests using email and keeps information about company laptops, monitors and other equipment in several spreadsheets.
This system has become difficult to manage.
Problems include:
•	IT requests being forgotten.
•	Employees not knowing the status of their requests.
•	No central history of previous problems.
•	Difficulty determining who currently owns a company device.
•	Duplicate information across spreadsheets.
•	Poor reporting on common IT problems.
•	No clear record of changes made to support requests.
The company wants a new internal system called NexusDesk.

# Project Objective
Design and develop a software system that allows Northstar employees and IT staff to manage:
•	IT support tickets
•	Employees
•	Company devices/assets
•	Ticket comments
•	Ticket history
•	Basic reports and statistics
The application must store its information permanently in a relational database.
The system should be designed so that additional features could be added in the future.
